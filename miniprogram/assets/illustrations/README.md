## 配色

- 宣纸：`#f5f0e6`
- 松石绿：`#2f4a46`
- 朱砂红：`#b53b2e`
- 赭金：`#c39445`
- 灰墨：`#7f8677`

SVG 根节点没有背景填充；项目页面默认引用同名 PNG，确保微信开发者工具和真机渲染一致。宣纸纹理建议以低透明度使用，避免影响文字对比度。

四张叙事插图均使用与页面一致的宣纸底色，构图重点集中在右侧与底部，左上保留文案安全区；空状态应按页面语义选用对应素材，不交叉复用，也不应用在真实模板封面或用户编辑画布上。
